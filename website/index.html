Track work

  1. Create a job and select it in the work screen.
  2. Start the timer. Stop it when you finish.
  3. Open the job’s work history to review or correct an entry.

Manual timekeeping works without location access.

Automate work sites

  1. Open the job’s work sites and add a site with a location and radius.
  2. Enable automation and choose whether arrival starts the timer and departure stops it.
  3. Grant precise location and background access where Android requires it.
  4. Check the monitoring status, then leave the site and return for a fresh arrival.

If a transition is missed, confirm the site and the relevant arrival or departure action are enabled. Use Refresh site monitoring or Retry site monitoring if shown, then leave the site and return once monitoring is ready.

Android can delay or miss transitions. Use manual timing when automation is unavailable.

Back up and restore

  1. In Settings, open Export encrypted backup and choose a password.
  2. Save the encrypted file to a location you can access later. Keep the password separately.
  3. To restore, stop your timer, open Restore encrypted backup, and select the file.
  4. Enter the password, review the proposed merge and resolve any conflicts before applying it.

Clockrove cannot recover backup passwords. Imported site automation starts disabled.

Manage saved location

Use Settings to choose the default for work location recording, or change it for a specific job. Site automation is controlled separately.

Use location history deletion to remove GPS points without deleting timesheets. Backups and exports you already saved are managed at their destination.

Organize jobs and tasks

  1. Open a job’s board and add a task to a column.
  2. Use the task’s move action as work progresses.
  3. Reuse a saved task from the library when creating a new card.

Archive a finished job to remove it from active lists while preserving its history.

Run reports and export CSV

  1. Open Reports from the main menu or Job report from a board.
  2. Choose the date range and jobs. Review the totals for the selection.
  3. Export CSV, pick a destination, and review the file before sharing it.

Prepare quotes and invoices

  1. Open Quotes and prepare a quote for review.
  2. After acceptance, review what work belongs on the job.
  3. Check the customer, prices, and covered work before preparing an invoice.
  4. Open Invoices to view the saved PDF or record a payment.

Use the Android widget

  1. Open the Android launcher’s widget picker and add a Clockrove widget.
  2. Configure a default job or choose a job when you start work.
  3. Use the timer widget to stop the active job. Task widgets show upcoming work for their configuration.
