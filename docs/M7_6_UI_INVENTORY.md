# M7.6 whole-app UI and actual-route inventory

**Status:** preparatory inventory only. It describes source at `00b11b6` before
the M7.6 overhaul. No screen was redesigned and no M7.6 device or screenshot
evidence is claimed. Use this list to scope the later overhaul after M6.6 and M7
are complete; do not treat the checklist as a release gate pass.

M7.6 requires an actual-app journey, native persistence/side-effect assertions,
and reviewed screenshots on API 24 and the current Play-supported stable API
for every item below. Capture light and dark themes, narrow-phone layout and
large text. Include representative empty, loading, error/retry, permission
denial, cancellation and destructive-confirmation states where listed. Reopen
the relevant screen or process after saves to prove committed state. Keep only
synthetic data in artifacts.
